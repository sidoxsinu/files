[PROBLEM STATEMENT]
Demonstrate handling multiple built-in exceptions in a single try-catch structure:
- ArrayIndexOutOfBoundsException: Accessing invalid array index
- ArithmeticException: Division by zero when calculating average
- InputMismatchException: Non-numeric input provided via Scanner
- IllegalArgumentException: Mark entered outside 0-100 range
- finally block: Closes Scanner and prints completion message.
