[PROBLEM STATEMENT]
Demonstrate Exception Propagation across method call stack:
- Method 1: accessAccount(u, p) throws InvalidUserException, InvalidPasswordException
- Method 2: validateUser(u, p) calls accessAccount() without catching, propagating exceptions
- Method 3: login(u, p) calls validateUser(), propagating exceptions to caller
- Main method: Calls login() inside try-catch with a 3-attempt loop.
