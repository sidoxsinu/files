[PROBLEM STATEMENT]
Demonstrate multiple inheritance via interfaces in Java:
- Interface 1: Payment (methods: processPayment(double a), generateReceipt())
- Interface 2: Refundable (method: processRefund(double a))
- Classes implementing both interfaces:
  * CreditCardPayment
  * UPIPayment
  * NetBankingPayment
Demonstrate interface reference variables and casting to access methods from both interfaces.
