[PROBLEM STATEMENT]
Create packages for a hospital management system:
- Package 'hospital.patient': Class Patient with:
  * private: recordNo
  * default: category
  * protected: treatment
  * public: name
  * public methods: getRecordNo(), addCharge()
- Package 'hospital.staff':
  * InPatient extends Patient (bill = treatment + 2000)
  * EmergencyPatient extends Patient (bill = treatment + 5000)
  * Main class with main() executing the billing
