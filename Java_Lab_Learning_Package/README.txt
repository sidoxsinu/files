================================================================================
JAVA LAB EXAM - COMPREHENSIVE LEARNING & STUDY PACKAGE
================================================================================

This package is designed specifically for learning and memorizing every single
Java program line-by-line for your lab examination.

--------------------------------------------------------------------------------
FOLDER STRUCTURE PER PROGRAM:
--------------------------------------------------------------------------------
Each program folder (e.g., 01_StudentResult, 16_BankingPackageAccess, etc.) contains:

1. Original Source Code (.java):
   - The exact, minimal, comment-free code required for your exam.
   - Code is 100% identical to the exam package ("don't change the code").

2. Explanation.txt:
   - Complete line-by-line breakdown of every line in every source file.
   - Explains what each line does in plain English.
   - Details every Java keyword (class, public, static, void, this, super, extends,
     implements, abstract, interface, throws, throw, try, catch, finally, synchronized).
   - Explains memory allocation, method calls, polymorphism, and runtime behavior.
   - Shows step-by-step program execution flow from start to finish.

3. run.txt:
   - The exact compilation and execution commands for Linux terminal.

4. temp/ Folder:
   - Algorithm.txt (step-by-step logic for writing in exam answer sheets).
   - Output.txt (exact console output).
   - Viva.txt (targeted viva questions and concise answers for external examiners).

--------------------------------------------------------------------------------
HOW TO STUDY EACH PROGRAM:
--------------------------------------------------------------------------------
1. Open 'Explanation.txt' in any text editor (Notepad, nano, gedit, VS Code).
2. Read the Problem Statement and Full Code with line numbers.
3. Read through the "Line-By-Line Explanation" to understand what every keyword
   and statement achieves.
4. Practice typing the minimal .java file from memory into a Linux terminal.
5. Compile and run using the commands in 'run.txt'.
6. Check 'temp/Viva.txt' to prepare for viva voce questions.
================================================================================
