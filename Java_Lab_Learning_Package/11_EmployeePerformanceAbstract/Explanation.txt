[PROBLEM STATEMENT]
Create an abstract class Employee with an abstract method calculateSalary().
Implement subclasses:
- Manager: Basic + 20% DA + 10% HRA + 5000 bonus
- Developer: Basic + 20% DA + 10% HRA + 3000 bonus
- Intern: Basic + 1000 stipend
Demonstrate runtime polymorphism by storing objects in an Employee array.
