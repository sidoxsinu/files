[PROBLEM STATEMENT]
Create an abstract class Payment with transaction ID, amount, and an abstract method
processPayment().
Subclasses:
- CreditCardPayment: 2% processing fee, Rs. 100 reward points if amount >= 5000
- UPIPayment: 0.5% fee, Rs. 50 cashback if amount >= 1000
- NetBankingPayment: Rs. 20 flat fee, Rs. 100 discount if amount >= 5000
Execute transactions polymorphically via an array of payments.
