[PROBLEM STATEMENT]
Create an abstract class Product with an abstract method calculateFinalPrice().
Implement concrete subclasses:
- Electronics: 18% GST + 500 shipping
- Clothing: 10% discount if total >= 2000, then 5% GST
- Grocery: 5% bulk discount if qty >= 10, then 5% GST
Demonstrate polymorphic billing across all product types using an array.
