[PROBLEM STATEMENT]
Implement comprehensive hospital billing with multiple modular methods declaring exceptions:
- InvalidPatientException: If patient ID <= 0
- InvalidChargeException: If any charge component is negative
- PaymentException: If amount paid is less than total bill
All methods propagate exceptions up to generateBill(), which is called in main()
inside a try-catch-finally block.
