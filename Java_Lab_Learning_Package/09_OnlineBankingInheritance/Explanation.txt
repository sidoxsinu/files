[PROBLEM STATEMENT]
Implement account inheritance with multilevel and hierarchical branches:
- Base class: Account (balance, deposit, withdraw)
- SavingsAccount extends Account (calculates 5% interest)
- PremiumSavingsAccount extends SavingsAccount (adds loyalty benefit if balance >= 50,000)
- CurrentAccount extends Account (applies penalty of 500 if balance drops below 10,000)
