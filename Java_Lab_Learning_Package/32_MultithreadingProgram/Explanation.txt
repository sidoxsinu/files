[PROBLEM STATEMENT]
Implement multithreading and thread synchronization in Java:
- Part 1: Thread creation by extending Thread class. Create two threads (Thread 1, Thread 2)
  that count numbers concurrently and demonstrate join().
- Part 2: Thread synchronization using 'synchronized' methods. Create a shared Bank account
  with balance 1000. Launch two concurrent Customer threads ("Arun" requesting 700,
  "Anu" requesting 500) attempting to withdraw at the same time. The synchronized method
  prevents race conditions and ensures mutual exclusion.
