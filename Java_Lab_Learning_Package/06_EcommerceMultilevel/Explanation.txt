FILE: SmartPhone.java
================================================================================

[PROBLEM STATEMENT]
Implement multilevel inheritance in an e-commerce context:
- Base class: Product (id, name, price)
- Intermediate class: ElectronicProduct (warranty, GST) extends Product
- Derived class: SmartPhone (storage, insurance) extends ElectronicProduct
Calculate GST, add insurance, and display the final price.
