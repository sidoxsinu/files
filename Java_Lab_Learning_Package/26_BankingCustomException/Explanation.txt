[PROBLEM STATEMENT]
Create user-defined custom exceptions in Java:
- InsufficientBalanceException: Thrown when withdrawal exceeds available balance.
- InvalidAmountException: Thrown when deposit or withdrawal amount is <= 0.
Implement a BankAccount class with deposit() and withdraw() methods declaring
these exceptions via 'throws', and handle them using try-catch-finally in main().
