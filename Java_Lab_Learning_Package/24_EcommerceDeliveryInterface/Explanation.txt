[PROBLEM STATEMENT]
Implement delivery options using multiple interfaces:
- Interface 1: DeliveryService (calculateDeliveryCharge(dist, wt), estimateDeliveryTime())
- Interface 2: Trackable (trackOrder(), updateLocation(loc))
- Implementing classes:
  * StandardDelivery: dist*2 + wt*10, 5 days
  * ExpressDelivery: dist*5 + wt*20, 2 days
  * InternationalDelivery: dist*10 + wt*30 + 500 customs fee, 10 days
Demonstrate polymorphism and interface casting.
