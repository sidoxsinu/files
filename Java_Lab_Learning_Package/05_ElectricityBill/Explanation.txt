[PROBLEM STATEMENT]
Create an ElectricityBill class to calculate electricity bills based on units consumed:
- Up to 100 units: Rs. 2 per unit
- Next 100 units (101 to 200): Rs. 3 per unit
- Above 200 units: Rs. 5 per unit
Demonstrate slab calculation for multiple consumers.
