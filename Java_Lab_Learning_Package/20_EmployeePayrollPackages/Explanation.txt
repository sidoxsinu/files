FILES: Employee.java, Manager.java, PayrollManager.java

[PROBLEM STATEMENT]
Create packages for employee payroll:
- Package 'company.employee': Class Employee with:
  * private: id, basic
  * default: dept
  * protected: grade
  * public: name
  * getters: getId(), getBasic()
- Package 'company.payroll': Class Manager extends Employee
  * Adds bonus = 5000, calculates salary = getBasic() + bonus
- Package 'company.management': Class PayrollManager with main()
  * Demonstrates access across three distinct packages.
