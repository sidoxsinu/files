[PROBLEM STATEMENT]
Implement nested try-catch blocks in an online order checkout system:
- Outer try block: Validates product selection. Throws InvalidProductException if ID not found.
- Inner try block: Validates stock availability. Throws OutOfStockException if quantity requested > stock.
- Order processing: Deducts stock and prints confirmation.
