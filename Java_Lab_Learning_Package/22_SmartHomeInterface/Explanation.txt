[PROBLEM STATEMENT]
Implement smart home devices using multiple interfaces:
- Interface 1: SmartDevice (turnOn(), turnOff(), displayStatus())
- Interface 2: EnergyMonitor (calculatePowerConsumption() returning energy in kWh)
- Classes implementing both interfaces:
  * SmartLight: 15W rating for 6 hours daily -> (15 * 6) / 1000 = 0.09 kWh
  * SmartFan: 75W rating for 8 hours daily -> (75 * 8) / 1000 = 0.6 kWh
  * SmartAC: 1500W rating for 5 hours daily -> (1500 * 5) / 1000 = 7.5 kWh
Use an array of SmartDevice and interface casting to show status and power consumption.
