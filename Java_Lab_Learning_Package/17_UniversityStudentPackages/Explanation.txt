================================================================================
PROGRAM 17: UNIVERSITY STUDENT PACKAGES & ACCESS SPECIFIERS
FILES: Student.java, ResearchStudent.java, Admin.java
================================================================================

[PROBLEM STATEMENT]
Create packages demonstrating access modifiers in university administration:
- Package 'college.student': Class Student with:
  * private: id (accessible via public getId() / setId())
  * default: dept (accessible via public getDept() / setDept())
  * protected: cgpa
  * public: name
- Package 'college.faculty': Class ResearchStudent extends Student
  * Accesses protected cgpa and public name in subclass show()
- Package 'college.admin': Class Admin with main()
  * Demonstrates public access and getter/setter encapsulation.
