FILE: Main.java

[PROBLEM STATEMENT]
Create an abstract class Transport with vehicle number, distance, and passengers.
Abstract method: calculateFare().
Implement subclasses:
- Bus: distance * passengers * 2
- Taxi: (distance * 15) + (passengers * 50) + 100 booking fee
- ElectricVehicle: (distance * 8) + (passengers * 20) + 50 base fee
Demonstrate dynamic fare calculation for all modes of transport.
