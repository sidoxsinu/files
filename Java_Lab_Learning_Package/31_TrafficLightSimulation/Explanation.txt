[PROBLEM STATEMENT]
Simulate a traffic light control system using a switch-case statement:
- Read traffic light color (RED, YELLOW, GREEN) from console input.
- Convert input to uppercase to handle case-insensitivity.
- Actions:
  * RED -> Print "STOP"
  * YELLOW -> Print "READY"
  * GREEN -> Print "GO"
  * Default -> Print "Invalid colour"
