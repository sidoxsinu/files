FILE: Main.java

[PROBLEM STATEMENT]
Create an abstract class Patient with abstract method calculateBill().
Subclasses:
- InPatient: (room rent * days) + treatment + doctor fee
- OutPatient: consultation fee + medicine
- EmergencyPatient: treatment + emergency surcharge + doctor fee
Demonstrate polymorphic billing across patient categories using an array.
