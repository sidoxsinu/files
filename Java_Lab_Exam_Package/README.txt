JAVA LAB EXAM PACKAGE (FOR LINUX TERMINAL)
===========================================

1. HOW TO RUN ANY PROGRAM ON LINUX:
   Open terminal inside the program folder (or cd into it), then open 'run.txt' to see the exact commands.
   Example:
     javac Main.java
     java Main

2. FOR PACKAGE PROGRAMS (16 to 20):
   Just run:
     javac -d . *.java
     java package.name.Main
   (All commands are directly in run.txt)

3. CLEANUP BEFORE EXAM:
   All Viva questions, Algorithm, and Sample Outputs are placed in a 'temp' folder inside each program.
   To delete them in Linux, run:
     rm -rf temp
   Only the essential .java files and run.txt will remain.
